# Say in Japan

> 面向日本旅游、留学生、短期居住者的离线日语口语助手

## 功能

- **318 句实用日语**，覆盖 6 个场景（交通、购物、餐饮、应急、互动、车站）
- **一键发音** — 点击即 TTS 朗读（ja-JP），语速已调整
- **10 个意图快捷筛选** — 多少钱、在哪里、免税、抽烟等
- **实时搜索** — 中日文 + 标签模糊匹配
- **收藏 & 常用短语** — 自定义快捷栏，可排序
- **应急功能** — 110/119 一键拨打，中国驻日使领馆信息
- **完全离线** — PWA，添加到主屏幕后无需网络
- **194 句带中文谐音** — 帮助零基础发音

## 使用方法

1. Safari 打开 [https://guofjapan-dotcom.github.io/say-in-japan/](https://guofjapan-dotcom.github.io/say-in-japan/)
2. 点击底部「分享」→「添加到主屏幕」
3. 安装后即可离线使用

## 技术栈

纯前端 — Vanilla JS + CSS，Python http.server 本地开发，GitHub Pages 部署。
