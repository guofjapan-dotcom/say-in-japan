# Say in Japan

> 日本生活场景沟通工具 — 帮你快速说出第一句日语

## 这是什么

Say in Japan 是面向**日本旅游、留学、工作、生活**的中国人的离线日语口语助手。

不是 AI 聊天，不是翻译软件，不是日语学习 App。

**场景化短语速查 + 一键发音 = 直接开口说。**

## 功能

- **487 句实用日语**，覆盖 9 个场景（交通、餐饮、医疗、购物、住宿、互动、应急、行政手续、金融支付）
- **5 阶段行为流程** — 每个场景按「进入→核心操作→信息确认→问题处理→结束」组织，秒找句子
- **一键发音** — 点击 TTS 朗读（ja-JP）
- **10 个意图快捷筛选** — 找地方、问价格、怎么走、支付、求助、许可等
- **实时搜索** — 中日文 + 标签 + 意图模糊匹配
- **对话补救** — "对方没听懂？"三张卡片推荐下一句
- **收藏 & 常用短语** — 自定义快捷栏，可拖拽排序
- **应急功能** — 110/119 一键拨打，5 个中国驻日使领馆信息
- **中文谐音全覆盖** — 487 句全部带谐音标注，零基础开口
- **完全离线** — PWA，添加到主屏幕后无需网络

## 使用方法

1. Safari 打开 [https://guofjapan-dotcom.github.io/say-in-japan/](https://guofjapan-dotcom.github.io/say-in-japan/)
2. 点击底部「分享」→「添加到主屏幕」
3. 桌面图标点击即用，完全离线
