# Say in Japan

> 日本生活场景沟通工具 — 帮助不会日语的人快速完成现实沟通

## 这是什么

Say in Japan 是面向**日本旅游、留学、工作、生活**的中国人的离线日语口语助手。

不是 AI 聊天工具，不是翻译软件，不是日语学习 App。

是**场景化短语速查 + 一键发音**的实用工具。

## 功能

- **318 句实用日语**，覆盖 6 个场景（交通、购物、餐饮、应急、互动、车站）
- **一键发音** — 点击即 TTS 朗读（ja-JP），语速已优化
- **10 个意图快捷筛选** — 多少钱、在哪里、免税、抽烟、帮助等
- **实时搜索** — 中日文 + 标签模糊匹配
- **收藏 & 常用短语** — 自定义快捷栏，可拖拽排序
- **应急功能** — 110/119 一键拨打，中国驻日使领馆信息
- **完全离线** — PWA，添加到主屏幕后无需网络
- **194 句带中文谐音** — 零基础也能开口

## 使用方法

1. Safari 打开 [https://guofjapan-dotcom.github.io/say-in-japan/](https://guofjapan-dotcom.github.io/say-in-japan/)
2. 点击底部「分享」→「添加到主屏幕」
3. 桌面图标点击即用，完全离线
